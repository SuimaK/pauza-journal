# Пауза — дневник эмоционального состояния

Готовое веб-приложение для iPhone, смартфонов Android и компьютера. Интерфейс на русском языке.

## Что есть в приложении

- **5–6 ежедневных отметок** в выбранные часы (по умолчанию 09:00, 11:30, 14:00, 16:30, 19:00, 21:30). Отметки можно делать в любое время, пропускать без последствий.
- **Короткий опрос:** настроение, энергия, напряжение, физическое самочувствие, несколько эмоций, необязательная заметка и необязательная тяга к сладкому.
- **Практика «Четыре шкалы»:** нехватка впечатлений, времени для себя, общения и сила тяги к сладкому (0–10); дополнительно — потребности, в том числе желание «отключиться от мыслей».
- **Практика «Сладкое без автоматизма»:** три вопроса до/во время еды; можно сохранить первую часть и дополнить её позже, когда заметили изменение удовольствия.
- **Практика «Пауза между кусочками»:** при снижении удовольствия и сохранении желания продолжать — оценка тяги, вопрос о следующем кусочке, минутная пауза с таймером, повторная оценка и свободное решение продолжить или остановиться. Можно прекратить упражнение без оценки. Начало сохраняется, завершить можно позже.
- **Собственные задания психолога:** произвольные вопросы со свободными ответами или шкалой 0–10.
- **История и график за 7 дней**, простое сравнение записей о сильной и умеренной тяге к сладкому (не диагноз и не причинный вывод).
- **Локальное хранение** в браузере, экспорт и импорт резервных копий JSON без дублей.
- **Автономная работа** после первого открытия опубликованного сайта, с помощью service worker.

Приложение не предписывает диет, пищевых ограничений, компенсации съеденного или обязательного количества наблюдений.

## Как запустить на iPhone через GitHub Pages

1. Создайте **отдельный** GitHub-репозиторий, например `pauza-journal` (не используйте репозиторий с рецептами).
2. Загрузите **содержимое папки** `pause_journal_app` в корень репозитория: `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, папку `icons`.
3. В GitHub откройте **Settings → Pages → Build and deployment → Deploy from a branch**. Выберите `main`, каталог `/ (root)` и нажмите Save.
4. После публикации откройте появившийся адрес GitHub Pages в **Safari** на iPhone.
5. В Safari нажмите «Поделиться» → «На экран Домой». Запустите приложение с экрана Домой.
6. В приложении откройте «Настройки», задайте 5 или 6 времён и сохраните расписание.
7. Нажмите «Скачать напоминания для Календаря (.ics)». Добавьте события в Apple Calendar. При необходимости импортируйте файл через «Файлы», почту или другое устройство. Проверьте, что у Календаря включены уведомления.

Ссылка на GitHub Pages будет иметь вид `https://ВАШ_НИК.github.io/pauza-journal/`, если репозиторий назван `pauza-journal`. Фактический адрес посмотрите в настройках Pages.

Для локальной проверки на компьютере можно запустить HTTP-сервер в этой папке, например `python3 -m http.server 8000`, и открыть `http://localhost:8000/`.

## Важное ограничение уведомлений

Обычная веб-страница не может гарантированно запускать локальный таймер или показывать системные уведомления в закрытом Safari на iPhone. Для настоящих Web Push-уведомлений нужен отдельный сервер, который будет отправлять сообщения на подписанное устройство. **В этой версии системные напоминания реализованы через файл iCalendar**, содержащий отдельные события с ежедневным повторением (365 повторов) и сигналами в настроенные часы. Они приходят от приложения «Календарь», а не от «Паузы» напрямую. События следует импортировать вручную; импорт .ics в iOS может отличаться между версиями.

При изменении времени скачайте новый .ics и удалите прежние события во избежание повторов. Если открываете приложение в другое часовом поясе, сверяйте время напоминаний в Календаре.

## Приватность

- Записи сохраняются **только на устройстве и в том браузере, где открыта Пауза** (localStorage). Они не отправляются разработчику или в облако.
- Данные не зашифрованы отдельным паролем. Любой, у кого есть доступ к браузерным данным устройства, потенциально может получить к ним доступ.
- Удаление данных сайта/Safari может удалить дневник. Регулярно сохраняйте резервные копии через «Настройки».
- На разных устройствах дневники независимы. Для переноса используйте «Скачать резервную копию» и «Восстановить из файла».
- Не публикуйте файлы `.json` с персональными записями в публичном GitHub-репозитории.

## Разработка

Исходники — обычные HTML/CSS/JS, без сторонних библиотек, аналитики и внешних запросов. Для обновления достаточно заменить файлы в опубликованном репозитории. При изменениях service worker обновите константу `CACHE` в `sw.js`, чтобы iPhone не сохранил устаревшую версию.
